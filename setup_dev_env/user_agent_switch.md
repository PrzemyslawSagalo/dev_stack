# User agent switch
1. Get User-Agent Switcher extension for your browser.
2. If no Linux based agents appear in the extension you need to add it manually in the extension's settings. For me the following User-Agent string worked Mozilla/5.0 (X11; Ubuntu; Linux x86_64; rv:107.0) Gecko/20100101 Firefox/107.0
3. Then just simply activate the Linux based User-Agent profile and log in into the Citrix Workspace by clicking next on the window with More information required message and then skip the mobile phone authentication step.
